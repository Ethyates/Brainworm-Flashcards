🧠 Brainworm Flashcards

A browser-based flashcard study app designed to help knowledge burrow into your brain.

Built with HTML, CSS, and JavaScript, this project demonstrates dynamic user interaction, persistent data storage, and a multi-feature web application structure.

📌 Project Purpose

Brainworm Flashcards is a study tool that allows users to:

Create custom flashcards
Organize them by category
Study interactively
Track performance within a session

The goal is to provide a simple but effective way to reinforce learning through repetition and review.

⚙️ Features
📝 Create & Manage Cards
Add flashcards with question, answer, and category
Edit existing cards
Delete unwanted cards
Prevent duplicate questions
Input validation for all fields
📚 Card Library
View all saved cards
Search by keyword (question or answer)
Filter by category
Dynamically updates based on user input
🎯 Study Mode
Study all cards or filter by category
Flip cards to reveal answers
Mark answers as Correct or Incorrect
Tracks progress through the deck
🔁 Review Missed Cards
After completing a session, users can:
See their score (e.g., 7/10 correct)
Review only the cards they got wrong
Provides a focused second pass for better retention
💾 Persistent Storage
Uses localStorage to save flashcards
Cards remain available after:
Page refresh
Browser restart
